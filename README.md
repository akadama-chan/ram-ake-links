# 🔗 RAMあけリンク集 v1

URLや短いメモをブラウザ内に退避する、GitHub Pages向けの静的Webアプリです。

## ファイル
- `index.html`
- `style.css`
- `app.js`

## 主な機能
- URLまたはタイトルのどちらかがあればカード登録可能
- localStorage保存
- 編集・個別削除・全件リセット
- 新しい順／古い順の表示切替
- JSONバックアップ書き出し
- JSON読み込み・IDベースのマージ
- 衝突時「現在を残す／読み込み側を採用／どちらも残す」
- 人間向けHTMLアーカイブ書き出し
- PC／スマホのレスポンシブ表示

## iPhoneについて
Safariの通常タブだけを恒久保存先とは考えず、GitHub Pages公開後はホーム画面に追加して使うことを推奨します。JSONバックアップも併用してください。
